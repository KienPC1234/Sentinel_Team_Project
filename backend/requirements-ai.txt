# Dependencies bổ sung cho AI service dùng chung (backend/scripts/ai_service.py).

# Cài SAU khi đã cài backend/requirements.txt (venv chính đã có torch,
# torchvision, opencv, pillow, numpy, sentence-transformers, faster-whisper):
#
#   .venv/bin/pip install gdown
#   .venv/bin/pip install --no-deps vietocr==0.3.13
#
# Vì sao --no-deps cho vietocr:
#   vietocr khai báo albumentations/imgaug/scikit-image... Các gói này có thể
#   kéo opencv-python (trùng opencv-python-headless) hoặc hạ/đổi numpy, gây
#   xung đột với venv chính. Phần suy luận của vietocr chỉ cần gdown, yaml,
#   numpy, torch, requests, tqdm, einops, PIL, cv2 — đều đã có.
#
# Nếu cài trên máy sạch (chưa có torch/opencv), có thể dùng requirements-ocr.txt
# với venv riêng .venv-ocr; ai_service sẽ fallback sang bridge khi thiếu vietocr.
