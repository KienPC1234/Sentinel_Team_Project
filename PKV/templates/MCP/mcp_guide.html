Tải Script Python Độc Lập (Standalone MCP)

1 file ~24KB

Bạn không cần clone toàn bộ repository hay cài đặt mã nguồn dự án. Script chứa đầy đủ MCP server, công cụ an ninh và kết nối bảo mật tới ShieldCall API.

Tải Script (.py) Xem mã nguồn Raw
Lệnh tải file script bằng Terminal:
curl -sSL https://shieldcall.vn/mcp/download/ -o shieldcall_mcp.py
Độc lập 100% (Zero-Dependency):
Chạy trực tiếp với Python 3 có sẵn. Không cần chạy pip install. Python 3.8+

Nếu đặt cùng thư mục workspace bạn chỉ cần để shieldcall_mcp.py, hoặc điền đường dẫn tuyệt đối.

Mặc định là python. Nếu dùng macOS/Linux có thể đổi thành python3.

                    Lỗi "command not found: python" trong Claude / Cursor?
                

                

                    Trên macOS hoặc Linux, lệnh python mặc định có thể không trỏ đến Python 3 hoặc môi trường ảo dự án. Khắc phục bằng cách thay chữ python trong file cấu hình bằng đường dẫn tuyệt đối:
                

                

                    /usr/bin/python3
                

                
Mẹo: Mở Terminal và gõ which python3 (macOS/Linux) hoặc where python (Windows) để lấy chính xác đường dẫn.

                    Hạn mức gọi API được tính và làm mới (Reset) khi nào?
                

                

                    Mỗi tài khoản miễn phí được cấp 500 requests/ngày và 60 requests/phút. Hạn mức ngày được làm mới tự động vào 00:00 UTC (tức 07:00 sáng theo giờ Việt Nam). Bạn có thể theo dõi thanh dung lượng thời gian thực tại Dashboard cá nhân.
                

            


            

                

                    4
                    Triển khai qua mạng từ xa (SSE Transport / Docker)?
                

                

                    Nếu bạn muốn chạy MCP Server trên máy chủ Linux từ xa cho cả đội ngũ sử dụng mà không cần cài Python trên từng máy cá nhân, khởi chạy lệnh sau:
                

                

                    python shieldcall_mcp.py --transport sse --host 0.0.0.0 --port 8002
                

                
Khi đó phía Client chỉ cần khai báo: "url": "http://ip-may-chu:8002/sse".
